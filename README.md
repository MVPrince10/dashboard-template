# dashboard-template

Fork of [TailAdmin React](https://tailadmin.com/) — a free open-source admin dashboard template built with React, Vite, and Tailwind CSS.

Used as a reference/starting point for dashboard UIs in other projects.

## Stack

- React + Vite
- Tailwind CSS
- ApexCharts
- JSVectorMap

## Dev

```bash
npm install
npm run dev
```
